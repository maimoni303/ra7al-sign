# رحّال للتوقيع | RA7AL Sign

برنامج مجاني يعمل على سيرفرك المنزلي (ZimaOS أو أي Docker) لتوقيع تطبيقات الآيفون (IPA) بشهادة **حساب المطوّر الخاص بك** وتثبيتها مباشرة على جوالك وأجهزة عائلتك.

- **ربط آلي بحساب آبل** عبر مفتاح App Store Connect API: إنشاء الشهادة، تسجيل الأجهزة، وتحديث ملف التعريف تلقائيًا.
- **تسجيل أجهزة العائلة برابط واحد**: يفتحه من Safari ويضغط «تثبيت» فيُضاف جهازه وتُعاد توقيع التطبيقات له.
- **تثبيت مباشر** على الآيفون من رابط آمن، وصفحة خاصة للعائلة بكلمة مرور.
- تنبيهات قبل انتهاء الشهادة (عبر n8n ← واتساب)، وتجديد تلقائي لملف التعريف.
- عربي / English، فاتح / داكن، ويُضاف للشاشة الرئيسية كتطبيق.
- بديل يدوي: رفع ملف ‎.p12 وملف ‎.mobileprovision جاهزين.

## التشغيل
```bash
docker compose up -d   # ثم افتح http://<السيرفر>:8787
```
التثبيت على الآيفون يحتاج رابط https موثوق (مثل Tailscale Funnel). اضبطه في `PUBLIC_URL` أو من الإعدادات.

## ملاحظات
- شهادة المطوّر مخصصة لأجهزتك وأجهزة من تديرهم. لا توزّع التطبيقات الموقّعة علنًا حتى لا تُلغى الشهادة.
- مفاتيحك وشهاداتك تُحفظ داخل مجلد `/data` على سيرفرك فقط، ولا تُرسل لأي جهة غير آبل.
